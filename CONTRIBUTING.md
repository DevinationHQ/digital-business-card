# Contributing

This is a review candidate. Public issue/discussion destinations will be established at release.

For a change, describe the user problem and provide reproduction steps or a before/after using fictional details. Check desktop and narrow mobile layouts, keyboard use and reduced motion. Run `npm test` and `npm run build`.

Keep this edition static and independently hostable. Propose contact storage, analytics, auth or integrations separately rather than silently adding services. Check the licence and provenance of new code, fonts and assets. Never submit real collected contacts or private card backups.

Theme contributions should preserve legibility and keep visual choices in CSS tokens. Do not claim a theme, example or community contribution is officially endorsed without permission.
