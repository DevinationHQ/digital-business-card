# Security and personal information

This kit publishes the profile and files you put in your public repository. Include only information you intend to share. Never upload contact databases, credentials, owner IDs, private media or `.env` files.

The editor processes JSON locally, validates URL protocols and inserts profile text as text rather than HTML. It is not a login system or remote admin panel. Public profile data is not secret because a page has no visible link to its JSON.

Use the private [Report a vulnerability](https://github.com/DevinationHQ/digital-business-card/security/advisories/new) form for security reports. Do not post exploit details or personal data in public issues.

No security audit or support SLA is claimed for this project.
