# Add a web app to your phone home screen

Use this for any web app: open its clean published address first, without a draft query or in-page fragment. Name the icon, add it, then launch it to check the destination. The icon may be generated from the site; a branded app icon is not guaranteed.

## Safari on iPhone

On the tested iPhone: **More (…) → Share → View More → Add to Home Screen**. Scroll if needed. Other Safari layouts offer Share directly or through the Page Menu. Edit the name, leave **Open as Web App** enabled where offered, and tap **Add**. Open the icon from your Home Screen. If Add to Home Screen is missing, check Edit Actions.

## Chrome on iPhone

Tap **Share** beside the address bar, choose **View More**, then scroll to **Add to Home Screen**. Edit the name, leave **Open as Web App** enabled where offered, and tap **Add**. Launch the icon and confirm the intended page. This route was checked on a real iPhone; menu positions can change.

## Chrome on Android

Google documents **More → Install and create shortcut → Install** where available. Other sites may offer Add to Home screen/Create shortcut instead. Follow the actual menu and confirmation on your device. This Android route is based on Google documentation; it was not hardware-tested in this release.

A Home Screen icon does not guarantee offline operation, notifications or native app features. Those depend on the website and operating system. Do not save a private test address for public sharing.
